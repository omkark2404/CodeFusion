# Contributing to CodeFusion

First off, thanks for taking the time to contribute! CodeFusion is an open-source project and we love receiving pull requests.

## How to Contribute
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes (`npm test`).
5. Make sure your code lints (`npm run lint`).
6. Issue that pull request!

## Code Style
- Use 2 spaces for indentation.
- We use Prettier for formatting and ESLint for linting. Run `npm run format` and `npm run lint` before committing.

## Reporting Bugs
- Use the GitHub Issues tracker to report bugs.
- Include OS, browser version, and steps to reproduce.
